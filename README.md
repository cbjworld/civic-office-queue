# 공공기관 대기 호출기 · Civic Office Queue

간부실이나 상담실을 방문할 직원이 자기 PC에서 대기를 등록하고, 담당자가 다음 사람을 호출하는 Windows 내부망 프로그램입니다. 기관명과 부서명은 설정으로 바꿀 수 있습니다. 계정 가입이나 제품 인증은 없습니다.

## 처음 배포할 때
1. Windows PC에 Python 3.14를 설치하고 이 저장소의 소스 ZIP을 풀어 주세요.
2. `organization.json`을 메모장으로 열어 기관명과 부서를 수정하세요. 예를 들어 중앙부처는 `{"organization":"예시부","offices":["장관실","차관실"]}`, 지자체는 `{"organization":"예시시","offices":["시장실","부시장실","민원상담실"]}`처럼 적습니다.
3. 해당 폴더에서 아래 명령으로 설치하고 빌드합니다.
```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python build.py
```
4. 각 부서 PC에는 `release/간부방호출기.exe`와 `release/organization.json`을 같은 폴더에 복사하고, 첫 실행에서 담당 부서를 선택하세요. 특정 부서 전용으로 쓰려면 호출기 복사본을 설정에 있는 이름 그대로, 예를 들어 `시장실호출기.exe`로 바꾸세요.
5. 직원 PC에는 `release/직원용번호표.exe`와 **같은 설정 파일**을 복사하세요. 설정 변경 시 양쪽에 다시 배포하고 재시작하면 됩니다. 재빌드는 필요 없습니다.

## 연결과 데이터
한 PC에서 호출기 하나를 운영하며 직원용은 함께 실행해도 됩니다. 호출기 첫 실행 시 직원이 접속할 내부망 IPv4 주소 하나를 선택합니다. 로컬 시험만 하려면 127.0.0.1을 선택하세요. 직원용은 내부망에서 자동 검색을 시도합니다. 자동 검색이 안 되면 직원용의 **서버 연결 설정**에 부서 PC의 IPv4 주소를 입력하세요. 호출기 PC 방화벽은 기관 내부 대역에서만 TCP 8000(대기 처리), UDP 8001(자동 검색)을 허용하세요. 직원 요청을 인증하지 않으며 통신이 암호화되지 않으므로 서비스 포트를 인터넷에 공개하지 마세요. 공개 저장소는 프로그램 배포용입니다.

대기 목록과 설정은 각 PC의 `%LOCALAPPDATA%\CivicOfficeQueue`에 저장됩니다. 기존 기관 전용판의 데이터를 자동 이전하지 않습니다. 부서명을 바꾸면 다른 대기열로 취급되므로 대기를 모두 처리한 후 변경하세요. 창을 닫아도 알림 영역에서 계속 실행됩니다.

## 개발자용
```powershell
.\.venv\Scripts\python -m unittest discover -v
.\.venv\Scripts\python server_office.py
# 다른 창에서 실행
.\.venv\Scripts\python client_app.py
```
직원용 기능은 등록, 취소, 순번 조회와 호출 알림입니다. 담당자는 호출기에서 재실 상태 및 대기 순서를 관리합니다. 웹 화면은 포함되어 있지 않습니다.
